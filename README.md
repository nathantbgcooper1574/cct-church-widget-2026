## Overview

CCT provides Wix websites with a structured Orthodox church calendar that presents information one day at a time. Its compact layout helps site visitors find saints, notes, and significant dates without navigating away from the page.

The widget is built for multilingual calendar projects that need a straightforward setup. Automatic CSV source detection helps organize calendar content and makes it easier to maintain data for multiple language versions.

## Settings and Data

The widget's configuration is generally managed through its settings together with the connected CSV file.

Common settings include:

- `language`: chooses the language used for display
- `dataSource`: identifies the CSV calendar file
- `highlightSundays`: turns Sunday emphasis on or off
- `highlightMarkedDays`: controls emphasis for marked dates

For deployments that keep configuration in separate files, make sure display preferences and CSV sources remain synchronized across pages and language versions.

## Frequently Asked Questions

**Can the calendar be displayed in multiple languages?**  
Yes. CCT includes multilingual support for localized calendar presentations.

**What format supplies the calendar data?**  
The widget uses CSV data and can automatically detect supported CSV sources.

**Are saints and notes included in the daily view?**  
Yes. Each day card can show its associated saints and notes.

**Can important dates be highlighted?**  
Yes. Sundays and marked days can receive distinct visual emphasis.

**How is CCT configured?**  
Most options are managed through the widget settings and its connected data source. If a particular build uses separate settings files, update those together with the CSV content.

**What should I check if the calendar is not rendering correctly?**  
Review the CSV structure, make sure the widget has been embedded correctly in Wix, and confirm that the selected language and data source correspond to the available content.
